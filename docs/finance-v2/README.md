## 一頁摘要

**問題**：feat/finance 每次打開頁面都從課卡、點名重新算「保管中」，鎖月靠 JSON 快照。數字對，但它不是一本帳：沒有科目、沒有分錄、看不到資產負債表／試算表、不能盤點對帳、只能以月為單位鎖、開帳日綁死在啟用那天。給一般人用很直覺，給管錢的人用就缺了會計該有的骨架。

**做法**：

1. **複式帳本**：每件事（賣卡、上課、付款、支出…）自動記成借貸平衡的分錄，存起來、只增不改。所有報表從分錄加總。
2. **分部是自己平衡的單位**：台南、高雄各有一套資產負債表；跨分部的錢用「分部往來」記，取代「丁丁欠 Sean」。
3. **資金帳戶**：每個人的口袋（或之後的教室專用戶頭）是一個現金科目，屬於某個分部。
4. **收入在上課時認列**，賣卡未收款記「應收」。老師仍然只拿收到的錢：學生沒付的那份記在「應付老師－待學生付款」，付款後自動轉成可發。
5. **過帳器**：營運資料一改，標記 dirty；讀財務前把差額記成新分錄。鎖帳期間的變動自動記到鎖帳日後一天。冪等，可以隨時全量重算檢查。
6. **鎖帳日**取代月結快照，任何一天都能鎖；**付款批次**（發老師錢、轉平往來）跟鎖帳分開，期間自由。
7. **任何一天開帳**：系統算預收、應收，人填資金帳戶與次數包，差額進各分部公積金；第一次鎖帳前可以換一天重開。
8. **報表**：總覽、損益表（分部並排）、資產負債表、現金流量、預收餘額、應收帳齡、應付明細／報酬單、課程獲利、試算表、總分類帳。每個數字都能點到分錄和來源。
9. **下一階段**才讓其他老師進來記帳（報帳單、我的報酬），帳本結構已經預留。
