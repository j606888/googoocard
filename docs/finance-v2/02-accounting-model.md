# 02 · 會計模型：科目、分部、每件事怎麼記

> 讀者：要實作或審查財務 v2 的人。先讀 [`README.md`](README.md)。
> 這份回答「每一件營運上發生的事，在帳上變成哪幾行分錄」。資料表與程式結構見 [`03-architecture.md`](03-architecture.md)。

---

## 1. 三個基本決定

### 1.1 真正的複式帳本
每一件事都寫成一筆**分錄**（journal entry），每筆分錄有兩行以上，**借貸相等**。報表（損益表、資產負債表、現金流量表、試算表）全部從分錄加總出來，不再各自重算。

金額慣例：`amount` 帶正負號，**正＝借（左）、負＝貸（右）**，每筆分錄 Σ = 0。

### 1.2 分部是「自己平衡的會計單位」
台南、高雄各自有一套完整的資產負債表（像總公司／分公司的「總分支機構往來」，或非營利組織的「基金會計」）：

- 每一行分錄都帶一個**分部**（`locationId`），而且**每筆分錄在每個分部內各自借貸平衡**。
- 一件事跨兩個分部時（例：丁丁在台南收錢賣的卡，拿去上高雄的課），系統自動補兩行 **分部往來**：台南「應付高雄」、高雄「應收台南」。
- 全教室的報表＝各分部相加；往來在相加時互相抵銷，剛好歸零。

這取代了 feat/finance 的「丁丁欠 Sean」：**欠的不是人，是分部**。月結時把往來轉平（台南的現金轉給高雄的現金），往來就歸零。

只有一個分部的教室（大部分教室）：永遠不會出現往來，跟一般小店的帳一樣。

### 1.3 錢放在誰手上＝「資金帳戶」
會計上把每個人的口袋當成公司的一個銀行戶頭。系統叫它**資金帳戶**（money account）：

| 欄位 | 例子 |
|---|---|
| 名稱 | 丁丁手上的現金、丁丁富邦帳戶（教室部分）、Sean 手上 |
| 種類 | 現金／銀行／電子支付 |
| 保管人 | 丁丁 |
| 分部 | 台南（這個帳戶裡的錢屬於哪個分部） |

- 一個人可以有好幾個資金帳戶；收款時選「收進哪個帳戶」（預設：收款人的預設帳戶）。
- **系統裡的餘額＝這個帳戶裡「屬於教室」的錢應該有多少**，不是戶頭的實際總額（私人帳戶混了私人的錢）。之後若開了教室專用帳戶，它就是一個種類＝銀行的資金帳戶，可以真的跟存摺對帳。
- 「賣卡分部」＝收款的資金帳戶的分部（feat/finance §5.1 的規則照舊：預設跟著收款人，可以改）。

## 3. 每件事怎麼記（過帳規則）

記法：`借 科目（分部）／貸 科目（分部）`。T＝台南、K＝高雄。所有例子用 feat/finance spec §13–14 的數字，**算出來的老師金額必須跟舊版一模一樣**（見 §5 驗收）。

### 3.1 賣卡
| 情況 | 分錄 |
|---|---|
| 已付款（收進資金帳戶 A，A 屬於分部 S） | 借 現金:A（S） 2,000 ／ 貸 預收（S） 2,000 |
| 還沒付款 | 借 應收學費（S） 2,000 ／ 貸 預收（S） 2,000；S＝這張卡目前的賣卡分部 |
| 之後收到款 | 借 現金:A（S） ／ 貸 應收學費（S） |
| 贈送卡、$0 卡 | 不記 |
| 改價、改收款帳戶、改賣卡分部 | 不手動改分錄：過帳器重算這張卡應有的分錄，記差額（見 03 §3） |

### 3.2 上一堂課（一個時段點完名）
**收入在上課那一刻認列，不管學生付了沒。** 每格價值＝實收 ÷ 格數（以「分」計，最後一格吃尾差，讓一張卡的預收剛好歸零）。

```
每一位用卡出席（或綁課卡缺席扣格）的學生：
  借 預收（卡的賣卡分部）  333.33
  貸 課程收入（這堂課的基金分部） 333.33
每一筆單堂：
  借 現金:A 或 應收學費（收款帳戶的分部） ／ 貸 單堂收入（這堂課的基金分部）
```
賣卡分部 ≠ 這堂課的基金分部時，自動補分部往來。

接著照**分帳規則**（feat/finance 的 `SplitRule`、`computeSplit()` 原封沿用）把成本記上：
```
借 老師報酬（基金分部）     ／ 貸 應付老師報酬（老師）或 應付老師報酬－待學生付款（老師）
借 場地費（基金分部）       ／ 貸 應付場地費（場地或成員房東）  或  預付場地費（次數包）
```
- 「公積金 10%」「剩下的 → 公積金」這種行**不記任何分錄**：沒分出去的就是這堂的利潤，自然留在分部的公積金裡。虧損（收入不夠付固定金額）也一樣自然變成負的利潤。
- 兼任老師的業主（丁丁、Sean）教課拿的錢是**老師報酬**，跟外師一樣是費用。這樣「分部賺不賺」跟「老闆當老師拿多少」分得開。
- 成員當房東（丁丁家）：場地費貸方記「應付場地費（房東：丁丁）」，月結時付給丁丁＝丁丁的個人收入。

**老師只分收到的錢（沿用 feat/finance 定案，只是記法變了）**
```
可發金額  = computeSplit(只算已付款的收入)
全部金額  = computeSplit(全部已認列收入)
待學生付款 = 全部金額 − 可發金額（每位老師各自算，最少 0）
```
可發的記在「應付老師報酬」，其餘記在「應付老師報酬－待學生付款」。學生付款時，過帳器重算那堂課，差額自動從「待學生付款」轉到「應付」。老師看到的「這個月可以領多少」跟 feat/finance 完全一樣；差別只在帳上看得到「還有 $X 等學生付款」。

確定收不到（學生跑了）：財務按「轉呆帳」→ 借 呆帳／貸 應收學費，並把那部分的老師待付沖回（借 應付老師報酬－待學生付款／貸 老師報酬）。

**沒點名的時段不記帳**（沿用）。點了名但這門課沒有分帳規則：收入照記，成本不記，結帳清單列為「有課沒設分帳」，設好之後過帳器自動補上。不再需要「未分配」格。

### 3.3 卡的其他事件
| 事件 | 分錄 |
|---|---|
| 轉換（舊卡剩餘價值變成新卡實收） | 借 預收（舊卡分部）／貸 預收（新卡分部，預設同舊卡） |
| 轉讓給另一位學生 | 同上 |
| 到期（已付款） | 借 預收（賣卡分部）剩餘價值／貸 過期收入（賣卡分部） |
| 到期（沒付款，從沒付過） | 借 預收／貸 應收學費：等於取消這筆應收 |
| 手動作廢 | 當作到期（沿用） |
| 退費（退 $1,000，剩餘價值 $1,333.33） | 借 預收 1,333.33 ／ 貸 現金:A 1,000 ／ 貸 過期收入 333.33 |
| 過期收入要給某位業主個人（分部設定） | 再加一筆**盈餘分配**：借 公積金（分部）／貸 應付業主款（某人）。見 §3.6 |

### 3.4 場地次數包
| 事件 | 分錄 |
|---|---|
| 買包 $4,050（Sean 從資金帳戶 A 付） | 借 預付場地費（A 的分部）／貸 現金:A |
| 上一堂用掉一次 | 借 場地費（基金分部）405 ／貸 預付場地費（包的分部） |
| 用超過（次數變負的） | 照上一包單價繼續貸預付場地費，餘額變負並提醒（沿用） |

### 3.5 支出、代墊
| 事件 | 分錄 |
|---|---|
| 台南 IG 廣告 $500，從丁丁手上的教室現金付 | 借 營業費用:廣告（台南）／貸 現金:丁丁（台南） |
| 同上但丁丁用**自己的錢**墊 | 借 營業費用:廣告（台南）／貸 應付業主款（丁丁）—— 教室欠丁丁，月結時還他 |
| 跨分部（Sean 的錢付台南的支出） | 照記，自動補往來 |

這就是外面系統的「代墊／請款」：區分「從教室的錢付」和「自己先墊」。

### 3.6 業主相關（權益）
| 事件 | 分錄 |
|---|---|
| 老闆放錢進教室 | 借 現金:A ／貸 業主投入 |
| 老闆從教室拿錢（不是報酬、不是分紅，例：先拿去用） | 借 業主提取 ／貸 現金:A |
| 宣告分紅（從公積金分給某人） | 借 公積金（分部）／貸 應付業主款（某人），之後付款 |

### 3.7 付錢、轉帳、盤點
| 事件 | 分錄 |
|---|---|
| 付老師、付房東、付外部場地、付業主款 | 借 應付…（對象）／貸 現金:A |
| 資金帳戶之間轉帳（丁丁轉給 Sean） | 借 現金:Sean（K）／貸 現金:丁丁（T），自動補往來；用來把分部往來轉平 |
| 發錢取整的零頭 | 借／貸 尾差（付款人的分部） |
| 現金盤點：系統說丁丁手上 $5,050，實際數到 $5,000 | 借 現金短溢 50 ／貸 現金:丁丁 50（並記盤點紀錄） |

### 3.8 手動分錄
可以結算的人可以記任何借貸平衡的分錄（更正、記帳士要求的調整、開帳後才想起來的舊帳）。**不能刪改已過帳的分錄**，只能「沖銷」（系統產生一筆完全相反的分錄）再重記。

## 4. 期初（開帳）
見 [`04-opening-and-cutover.md`](04-opening-and-cutover.md)。一句話：選任何一天當轉換日，系統產生一筆**期初分錄**，算得出來的（預收、應收、次數包）系統算，數得出來的（每個資金帳戶有多少）人填，差額進「期初權益調整」並轉入各分部公積金。

## 5. 必須成立的恆等式（寫成測試）

1. 每筆分錄：每個分部 Σ amount = 0。
2. 全教室：分部往來科目餘額合計 = 0。
3. 任何一天：預收（教室合計）＝ Σ 有效卡的剩餘價值（剩餘格數 × 每格價值）。
4. 任何一天：應收學費 ＝ Σ 未付款卡實收 ＋ Σ 未付單堂 − 已轉呆帳 − 已取消。
5. 任何一天：預付場地費（某場地）＝ Σ 包價 − 已用次數 × 單價。
6. 一堂課：收入 − 老師報酬 − 場地費 ＝ feat/finance `computeSplit` 算出的「進公積金」金額（含負數）。
7. 一位老師一段期間：應付老師報酬（可發）的增加 ＝ feat/finance 結算單上他的金額。spec §14 的十一月要逐元相等。
8. 資金帳戶餘額 ＝ 期初 ＋ 收款 − 付款 ± 轉帳 ± 盤點差。

## 6. 跟 feat/finance 的對照

| feat/finance（保管中模型） | v2（帳本） |
|---|---|
| 保管中各格加總＝現金 | 資金帳戶餘額＝現金；「各格」改成資產負債表 |
| 預收記在收款人身上 | 預收記在賣卡分部；錢在哪看資金帳戶 |
| 丁丁欠 Sean | 台南應付高雄（分部往來） |
| 已實現＝上課 ∧ 已付款才算收入 | 上課就算收入；只有「老師可發」看付款 |
| 未分配格 | 收入照記，成本等規則設好再補 |
| 公積金比例行 | 不記分錄，就是利潤 |
| 月結快照（JSON） | 鎖帳日＋不可改的分錄 |
| 調整行（鎖住後的差額） | 更正分錄（過帳器自動記在第一個沒鎖的日子） |
| 已轉 | 付款／資金帳戶轉帳分錄 |
| 分部核對（hash） | 結帳清單上的簽核項目 |
