# 05 · 畫面與報表清單（資訊架構，不是設計稿）

> 讀者：畫設計稿的 session、做前端的人。這份只定「有哪些畫面、每個畫面回答什麼問題、放哪些數字、誰能用」。長相、排版交給設計稿；遵守 `docs/ui-responsive.md`。

---

## 1. 設計原則

1. **財務頁是「介面越乾淨越好」的例外（Claude 的決定）**：會計軟體首頁一律先給幾個總覽數字。其他頁維持乾淨；說明一樣收進 ⓘ。
2. **先回答三個問題，細節點進去**：賺多少（損益）、錢夠不夠（現金 vs 欠的）、欠誰／誰欠我們（應付、應收）。
3. **每個數字都能點到分錄**（drill-down）：總覽 → 報表 → 科目明細 → 分錄 → 來源（那張卡、那堂課）。這是會計系統讓人信任的關鍵。
4. **分部切換器 + 日期區間** 在所有報表頁一致：全教室／台南／高雄；本月、上月、本季、今年、自訂。
5. **用語**：白話為主，報表上括號附會計名稱（「預收（預收收入）」）。

## 2. 導覽

```
財務
├─ 總覽            /finance
├─ 報表            /finance/reports            （清單頁，像 Xero 的 Reports）
│   ├─ 損益表       /finance/reports/pnl
│   ├─ 資產負債表   /finance/reports/balance-sheet
│   ├─ 現金流量     /finance/reports/cash-flow
│   ├─ 預收餘額     /finance/reports/deferred-revenue
│   ├─ 應收帳齡     /finance/reports/receivables
│   ├─ 應付明細     /finance/reports/payables
│   ├─ 課程獲利     /finance/reports/lessons
│   ├─ 試算表       /finance/reports/trial-balance
│   └─ 總分類帳     /finance/reports/general-ledger   （科目明細、分錄日記簿）
├─ 記一筆          （按鈕／抽屜：支出、代墊、轉帳、業主投入／提取、手動分錄）
├─ 結算與付款      /finance/payouts                 （付款批次、往來轉平）
├─ 資金帳戶        /finance/accounts                （每個口袋的餘額、明細、盤點）
```

## 3. 每個畫面

### 3.1 總覽 `/finance`
回答：這段期間賺多少？手上的錢夠還欠的嗎？有什麼要處理？
- **四到六個數字**：本期淨利（vs 上期）、資金帳戶合計（依保管人拆）、預收（還有幾堂沒上）、應付（老師／場地，含「待學生付款」小字）、應收（逾期的醒目）、各分部公積金。
- **償付測試一行**：現金 ≥ 預收 ＋ 應付？差多少（第 4 章《財務書》的那條線）。
- **6 個月趨勢**：收入、淨利、預收餘額三條線（或長條＋線）。
- **要處理的事**（沿用 feat/finance 首頁那份清單，沒有就不顯示）：未付款、沒綁卡、有課沒設分帳、過去沒點名、次數包用完、該鎖帳了、帳本健康檢查有問題。
- 可切分部、期間。

### 3.2 損益表
- 欄：分部並排（台南｜高雄｜全教室），或期間並排（本月｜上月｜去年同月）。
- 列：課程收入、單堂收入、過期收入、其他收入 → 收入合計；老師報酬、場地費 → **毛利**（＝原本的「進公積金」）；營業費用各子科目 → **淨利**。
- 每一格點進去 → 科目明細。

### 3.3 資產負債表
- 某一天（預設今天），分部並排。
- 資產：資金帳戶（逐個）、應收、預付場地、分部往來；負債：預收、應付老師（可發／待學生付款）、應付場地、應付業主；權益：業主投入、業主提取、公積金（期初＋累積淨利）。
- 底部檢查：資產 ＝ 負債 ＋ 權益 ✓。

### 3.4 現金流量（直接法，小教室版）
- 期初現金 → 收學費、收單堂 → 付老師、付場地、買次數包、支出、退費 → 業主投入／提取 → 期末現金。依資金帳戶可展開。
- 一行說明：淨利 vs 現金變動的差額主要來自預收變化。

### 3.5 子帳報表
- **預收餘額**：期初 ＋ 賣出 − 上課認列 − 過期 − 退費 ＝ 期末（rollforward），下面逐張卡：學生、卡號、剩格、每格價值、剩餘價值、到期日、賣卡分部。
- **應收帳齡**：未付款的卡／單堂，0–30／31–60／60+ 天，學生、金額、哪堂課用了；可「確認收款」「轉呆帳」。
- **應付明細**：依對象（老師、場地、業主）：可發、待學生付款、已付；點進去看每堂來源。也就是**老師報酬單**的來源。
- **課程獲利**：每門課／每堂：人數、收入、老師、場地、毛利、每人平均；損益兩平人數。

### 3.6 試算表、總分類帳
- 試算表：每個科目借方合計、貸方合計、餘額，總計借＝貸。給記帳士看。
- 總分類帳：選科目 → 期初、每筆分錄（日期、摘要、來源連結、借、貸、累計餘額）、期末。分錄日記簿：依日期列所有分錄。

### 3.7 記一筆（抽屜）
| 類型 | 欄位 |
|---|---|
| 支出 | 日期、金額、分部、類別（費用子科目）、付款方式：從哪個資金帳戶付／某人代墊、備註、收據照片（之後） |
| 轉帳 | 從資金帳戶 → 到資金帳戶、金額、日期 |
| 業主投入／提取／分紅 | 誰、金額、資金帳戶、分部 |
| 手動分錄 | 日期、摘要、多行（科目、分部、借、貸），即時顯示是否平衡；只有可以結算的人 |
已記的任何一筆：檢視、沖銷（不能刪改）。

### 3.8 結算與付款 `/finance/payouts`
- 建立付款批次：選截止日（預設上月底）→ 系統列出每位對象**截至那天可發**的餘額（老師、房東、外部場地、業主應付），每筆建議由誰從哪個資金帳戶付。
- **分部往來**：顯示台南 ↔ 高雄淨額，一鍵產生轉帳建議（一個淨額，像 Splitwise）。
- 取整：每筆付款取整到教室設定（1／10 元），尾差自動記。
- 每筆付款「等待付款／已付款」，付款人按已付款＝寫入付款分錄（沿用 feat/finance「付款人按已完成」）。
- **報酬單**：每位老師一頁：這期每堂明細、合計、待學生付款、已付。可分享給老師（之後老師登入自己看）。

### 3.9 資金帳戶 `/finance/accounts`
- 每個資金帳戶：餘額、明細（收款、付款、轉帳）、最後盤點日。
- **盤點**：輸入實數 → 顯示差額 → 確認寫入現金短溢。建議每月結帳前做一次。

### 3.10 結帳 `/finance/close`
結帳清單（一項一項打勾，全部完成才建議鎖，但不強制）：
1. 過去的時段都點名了
2. 未付款都處理了（收款或轉呆帳，或確認繼續等）
3. 每門有課的都設了分帳
4. 帳本健康檢查全綠
5. 每個資金帳戶都盤點了（可略過）
6. 各分部負責人看過損益表（簽核，取代分部核對）
7. 設定鎖帳日 → 鎖
顯示目前鎖帳日、鎖帳歷史、（owner）解鎖。

### 3.11 設定
科目表（加子科目、改名、封存）、分部（負責人、過期收入對象）、資金帳戶、老師付款人、場地、取整、開帳精靈（04）、重新檢查帳本。

## 4. 權限
| 動作 | 誰 |
|---|---|
| 看所有財務（第一階段全部透明，沿用） | 所有成員 |
| 記支出／轉帳／業主交易、付款按「已付款」 | 保管人（自己的資金帳戶）；可以結算的人（全部） |
| 手動分錄、沖銷、付款批次、改分帳規則與設定、開帳、鎖帳 | 可以結算的人 |
| 解鎖、重開帳 | owner |

## 5. 下一階段：讓老師進來記帳（先不做，架構已預留）
- **報帳單**：老師記一筆代墊（附收據）→ 狀態 草稿→送出→核准（可以結算的人）→ 過帳成「應付業主款／應付老師」並進下次付款批次。
- **我的報酬**：老師只看自己的報酬單與付款紀錄（此時才需要「依角色限制可見度」）。
- **老師收的錢**：老師也可以有資金帳戶（成為保管人），收款進自己的帳戶，結算時轉平。
這些都只是 v2 帳本上多一種來源與權限，不改帳本結構。
