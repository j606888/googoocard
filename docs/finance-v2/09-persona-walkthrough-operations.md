## 最大問題

### 🔴 1. 台南的課全記到高雄（是設計造成的，不是運算錯）
- 現象：損益表上台南收入 0、高雄 8,017（等於全教室）。總覽切到台南寫「還沒上過課」。付款批次把 Nini、俊彥&Fiona、台南舞蹈空間都算成高雄，還產生「分部往來轉平 台南→高雄 $4,600」。只有課程獲利報表的數字是對的。
- 原因（已查 code）：時段記在哪個分部，看的是**分帳規則的基金**（`src/service/ledger/load.ts:265`，`rule?.fundLocationId ?? p.lesson.locationId`），課程標的分部只是 fallback。agent 在第一步用「從另一門課複製規則」，把高雄 Bachata 的規則複製給台南的課，基金也就跟著變成高雄。
- 要決定：
  - 分部要不要一律照課程的 `locationId`，基金只決定剩下的錢進哪個公積金？
  - 或至少在規則的基金和課程分部不同時，大聲警告；複製規則時改成這門課自己分部的場地和公積金。
  - 第 2 步寫「課在哪個分部上，收入就記在哪個分部」，和實際行為相反。

### 🔴 2. 結帳頁的「帳本健康檢查：1 個問題，有紀錄記不進帳本」點不進去

## 報表評語與建議

| 報表 | 回答什麼問題 | 建議 |
|---|---|---|
| 課程獲利 | 哪門課賺、哪門課虧（最有感） | **保留**，加分部欄 |
| 損益表 | 台南、高雄各賺多少 | **保留**（先修好分部歸屬）；數字要能點進明細 |
| 應收帳齡 | 誰還沒付 | **保留** |
| 應付明細 | 還要付誰 | 併進「結算與付款」 |
| 現金流量 | 錢從哪來、去哪了 | 併進資金帳戶頁上方當月摘要；「期初現金 0＋期初分錄」合成一行 |
| 預收餘額 | 還欠學生幾堂課 | 從總覽的預收卡片點進去就好；「期初 0」會誤導 |
| 資產負債表、試算表、總分類帳 | 給記帳士用 | 收進「給記帳士」區 |

結算與付款：依「誰付」分組、標記已付款、作廢都好用。
結帳：清單附「去點名」「看應收帳齡」的連結很實用。

## 給老闆的操作建議（agent 版）
- **每天**：上完課點名，並按「完成點名」。賣卡時照實選現金／轉帳／還沒付，收款人選實際拿錢的人。
- **每週**：看「要處理的事」，收未付款的卡。有花錢就「記一筆 → 支出」。現金交給另一個人時，「記一筆 → 轉帳」。
- **每月 1–5 號**：
  1. 建付款批次，日期選上個月底。
  2. 付錢的人自己按「標記已付款」，不用另外記一筆轉帳。
  3. 有分部往來就轉平。
  4. 每個管錢的人盤點一次。
  5. 到結帳：兩個分部負責人各看一次損益表，最後鎖到上個月底。
- **每月看的報表**：課程獲利、損益表、應收帳齡，就夠了。
