| # | 優先 | 問題 | 建議 |

| S3 | 🟠 | 列表右側的綠色「B」圓徽章沒有說明（推測是 Bachata 資格或 LINE 綁定）。 | 換成有意義的圖示＋tooltip；如果是舞種資格，就用舞種顏色 badge（`danceStyleMeta`）。 |

## 建議處理順序

1. **先修會誤導的資料**：S1（最近上課日）、D1（無可用課卡文案）、D2（未來時段的點名提醒）、L1（載入中顯示 0）、I1（先重現）。
2. **列表可辨識度**：L2（期間與年份）、L3/S5（顯示程度）、S3（不明的「B」徽章）。
3. **桌面版版面**：G1（頂部 bar）、G2（寬度）、S4、I2/I3。
4. 其餘 🟢 項目順手打磨。
