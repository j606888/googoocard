# 財務輕量版（finance-lite）規格

> 2026-11-18 丁丁定案。取代 `feat/finance-v2`（會計帳本版，留在 worktree `../googoocard-finance-v2` 當參考，**不合併**）。
> 分支：`feat/finance-lite`，從 main 開。只回答兩件事：**每堂課的錢怎麼分**、**錢在誰那裡、誰欠誰多少**。不做開帳、科目、資產負債表、鎖帳、月結。

## 1. 背景

- Bailamore 有台南（丁丁負責）、高雄（Sean 負責）兩個分部。
- 到轉換日為止，所有卡錢都在 Sean 那裡。台南舊卡還沒上的課約 3 萬多（學生已付、還沒上），**不拿回來**。
- 轉換日起，台南新收的錢歸台南（丁丁收）。小幫手代收不細追，算進他所屬分部。
- 當天結：上完課當天付老師、場地，不改成月結。

## 2. 核心觀念：錢屬於分部，分部有負責人

- 每個分部有一位**負責人**（`Location.keeperUserId`，台南＝丁丁、高雄＝Sean），分部的錢實際在他手上。
- 每張卡記**錢屬於哪個分部**（`StudentCard.moneyLocationId`）：
  - 轉換日前的卡 → 高雄（Sean）。
  - 轉換日後 → 收款人所屬分部；在課堂上／LIFF 買的卡 → 那堂課的分部。可結算的人可以改。
- 每張卡也記**卡屬於哪個分部**（`StudentCard.homeLocationId`），決定到期沒用完的錢歸誰。新卡兩者相同；台南舊卡＝錢在高雄、卡屬台南。
- 單堂付費：錢屬於收款人所屬分部。

## 3. 分帳規則（從 v2 搬）

每門課設一條規則（`LessonSplitRule`），某一堂可以覆寫（`PeriodSplitOverride`）。規則由上而下扣：

- 固定金額 → 老師／場地
- 百分比（總收入或剩下的）→ 老師／場地／**這堂課的分部公積金**（例：台南的課 10% → 台南公積金）。不管卡錢屬於哪個分部，這 10% 都進開課分部。
- 場地費 → 場地（每次付的價，或次數包單價）
- **剩下的 → 卡錢的分部**（新的預設 rest target `holder`）；也可以指定給老師（比例分）或某分部公積金。

引擎沿用 v2 `src/domains/finance/split.ts` 的 `computeSplit()`（純函式＋測試）、`types.ts`、`ruleEditorModel.ts`、`RuleEditor.tsx`、`LessonSplitPanel.tsx`、`PeriodSplitRow.tsx`、`PayeePicker.tsx`、場地（`Venue`／`VenuePack`、`VenueSettings.tsx`、`PackForm.tsx`、`venueBilling.ts`）。不搬：帳本、資金帳戶、開帳精靈、報表、付款批次、鎖帳、結帳清單、使用教學、`AttendanceAbsence`／綁課卡。

**分部公積金＝分部的利潤**：剩下的錢進卡錢的分部，就是那個分部的公積金，不另分給個人。

## 4. 一堂課怎麼算

一個時段點完名後：

1. **收入** I ＝ Σ 每位學生這次扣掉的格數 × 卡的每格價值（實收 ÷ 總格數）＋ Σ 單堂付費。贈送卡、$0 卡算 0。
2. 照規則 `computeSplit(I)` 得到：老師 X、場地 Y、分部公積金 Z、剩下 R。
3. 把收入依**錢的分部**分堆：V_台南、V_高雄（I ＝ ΣV）。每一項成本與公積金照 V/I 比例由各堆負擔；剩下 R 的各堆份額留在自己的分部。

例：台南課，A、B、C 新卡（台南）各 $300、D、E、F 舊卡（高雄）各 $300，外師 $1,000，10% → 這堂課的分部（台南）公積金，剩下 → 卡錢分部。

| | 台南堆 $900 | 高雄堆 $900 |
|---|---|---|
| 外師 $1,000 | 500 | 500 |
| 台南公積金 10%（$180） | 90 | 90 |
| 剩下 $620 | 310 → 台南 | 310 → 高雄 |

丁丁當天付外師 $1,000 → 往來：**高雄欠台南 500 ＋ 90 ＝ $590**。

畫面上每堂顯示：收入、老師各拿多少、場地多少、各分部公積金多少。

## 5. 結清（當天付錢）

- 每個時段有「**已結清**」勾選＋「**誰付的**」（預設這堂課分部的負責人，可改）。勾了＝老師和每次付的場地費已經付出去。
- 勾之前提醒（不擋）：有學生沒卡、卡未付款、單堂未付、這門課沒有分帳規則。原則是錢收齊才勾。
- 勾的時候把算好的數字**存成快照**（`PeriodSettlement`），之後改點名或規則不會偷偷改掉已付的金額；要改就取消結清、重新勾。
- 往來怎麼記：
  - 付款人代表他負責的分部（Sean 在台南付外師 → 用高雄的錢付）。
  - 各堆負擔的老師費、每次付的場地費 → 該分部欠付款人的分部。
  - 次數包場地費：包當初是誰的分部付的，就欠那個分部。
  - 公積金份額 → 該堆的分部欠公積金所屬分部。
  - 同一分部自己欠自己不記。
- 沒結清的時段不進往來。

## 6. 到期

卡到期（或作廢）還有剩餘價值時：剩餘價值歸**卡屬於的分部**。若錢在別的分部（台南舊卡錢在高雄）→ 記往來：高雄欠台南剩餘價值。

## 7. 轉換日

每個分部一個轉換日（`Location.financeStartAt`）。轉換日前的時段、到期都不算。台南選上線那天；高雄可以同一天。

## 8. 往來面板與轉平

**「我欠誰／誰欠我」面板**（財務頁首頁，以登入者為主角）：

- 上方一行結論，從「我負責的分部」看：「你欠 Sean $590」或「Sean 欠你 $12,340」或「目前互不相欠」。不是分部負責人的成員看到全教室的分部間餘額。
- 下面是明細，新的在上，每一筆：日期、課程名＋時段、原因、金額、方向，點了開那堂課的結清內容。
  - 原因：「外師分攤」「場地分攤」「公積金 10%」「卡到期（#A0123 王小明，剩 3 格）」「轉帳」。
  - 同一堂課的多項合成一列，展開看細項（收入怎麼分、每堆負擔多少）。
- 可以篩月份。另外列出「還沒結清的課」（已點名、沒勾結清），提醒還有錢沒算進來。
- 「記一筆轉帳」：Sean 轉 $X 給丁丁（`BranchTransfer`），往來減少。
- Sean 在台南教課要拿的錢，可以直接用轉帳抵掉，不用真的付現。
