# 16 點名後收單堂／買卡：顯示收款人

Status: resolved
Type: task

財務開啟時，點名成功頁的「單堂 $400 → 收 $400」與「買卡並使用（已付款）」看不到收款人，不知道錢記在誰手上。顯示收款人（預設照 spec §8：自己是保管人就是自己，否則是該課分部負責人），可改成另一位保管人。其他收款入口（學生頁買卡、確認收款）一併檢查。

## Answer

財務開啟時，點名成功頁的單堂收款／單堂確認收款、買卡並使用、課程頁買卡、學生頁買卡都多了「收款人」選單（`src/features/finance/ReceiverField.tsx`，只列保管人；預設＝自己是保管人就自己，否則該課分部負責人，`src/domains/finance/receiverDefault.ts`；都沒有就必須選）。API（買卡、單堂）接受 `receiverUserId`，財務沒開時忽略；確認收款抽屜不再猜「第一位保管人」。體驗名單登記（已付）沒動，待決定。
