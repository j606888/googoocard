# 13 開帳：非保管人收的錢要改記到保管人名下

Status: resolved
Type: task

staging 走一遍（01）發現：上線日 11/1 到開帳當天之間賣的卡，收款人是 Nora、vv、Serena Chen（都不是保管人）。結果她們各自出現一張保管中，結算單還要「vv → 丁丁 $333」。

做法：開帳清單加一步「這些錢在誰手上」——列出收款人不是保管人的已付款卡／單堂（上線日之後），一鍵改記到一位保管人（預設＝舊卡保管人，可改成該分部負責人）。之後的收款本來就只能選保管人（spec §8），所以這是一次性的。保管中與結算單不應再出現非保管人。

## Answer
開帳清單新增 `receivers`（排在舊卡預收前）：`service/finance/strayReceivers.ts` 列出上線日後（建立或付款）已付款、收款人不是保管人的卡／單堂；`/api/finance/receivers` POST 把勾選的改記到一位保管人（可以結算的人才能按），卡沒有賣卡分部時補上該保管人負責的分部。
財務設定「上線後收的錢在誰手上」：預設全選、預設舊卡保管人；不同分部可分兩次改給各自負責人。測試 `tests/api/finance-receivers.test.ts`。
