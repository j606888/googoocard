# 水庫遊戲畫風：奇異鳥小鎮

做水庫的任何畫面前，先讀完 `docs/finance-game-style.md`（完整規格），金流規則讀 `docs/finance-plan.md`。下面是最常用、最容易做錯的部分。

## 比喻（不能改意思）

- 主堡 = 大水庫（老闆保管，不是老闆薪水）；倉庫箱子 1 箱 ≈ $1,000，只是示意。
- 代收人背包 = 代收；冒煙＋紅標 = 超過 N 天沒繳。
- 推車＋郵差奇異鳥＋❗ = 送出、等確認的繳回。推車停在主堡門口，沙漏條是「等了多久」，不是送達進度。
- 皇冠奇異鳥 = 營收負責人；只有他有「收到了／金額不對」。
- 建城貸款 = 欠老闆的；預收（灰）／待發（橘）／水庫基金（綠，真正能用）。
- 河兩岸 = 台南、高雄，**不各自存錢**；錢只有主堡一個庫。

## 規則

- 數字以 HUD、卡片、抽屜為準；每個遊戲畫面都有「帳本模式」。反過來，帳本看得到的每一筆，遊戲模式也要點得到（主堡＝主堡進出、人＝收款與送回紀錄、建築＝場地費）。
- 2:1 等角（半格 32×16），不描邊、三面三色、光從左上；Fredoka（數字）＋ Noto Sans TC（中文）；底色 `#FFFDF7`、地面 `#CDDA9F`、文字 `#4D4239`、等確認 `#F4A23C`、逾期 `#C4473A`、基金沿用 primary `#4BB38B`。
- 角色只用 Googoocard 奇異鳥，圍巾色＝這個人；不用其他遊戲的角色、圖像、Logo。
- 電腦 ≥ 1024px 橫式地圖＋左側背包卡；手機直式地圖（主堡上、河中、台南下）＋下方背包列（最左邊一顆動作鈕：送回主堡／記一筆，因為下面已有 App 的 BottomNav），點東西拉出下方抽屜。**不做自由縮放**。
- 點擊 ≥ 44px、地圖字 ≥ 11px、同時 ≤ 5 個泡泡、狀態要有字不只靠顏色、所有動畫有 `prefers-reduced-motion`。
- 帳本模式、表單細節、設定頁用一般設計系統（`docs/design-system.md`），不遊戲化。

## 工具

`docs/finance-game/gen_game.py`、`gen_mobile.py` 是產生設計稿的腳本，裡面的 `P()`、`box()`、`crate()`、`kiwi()`、`bubble()` 可以當等角幾何和角色的參考實作。`python3 docs/finance-game/gen_mobile.py` 會輸出到 `docs/finance-game/out/`。
